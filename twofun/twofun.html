TwoFun

A configurable USB keyboard utility

Paul Duke — Originally developed January 2024

During the COVID lockdowns, with so many people working from home, little USB devices designed to keep computers awake became increasingly popular. Rather than buying one, I decided to make my own. Of course, being a programmer, I couldn’t resist adding a few extra features. The result was TwoFun, a small, configurable USB device that doubles as a keyboard keep-alive and a programmable text-entry device.

Two Functions in One Little Box

TwoFun combines two simple USB keyboard utilities in a single device. The first keeps a computer awake by periodically generating keyboard activity. The second sends a predefined string of text whenever a pushbutton is pressed.

The device uses an ATmega32U4 microcontroller, which has native USB support and can emulate a keyboard without any special application software running on the host computer.

Run Mode

Both functions can be enabled or disabled independently. The keep-alive function sends two successive Caps Lock keystrokes at a configurable interval, restoring the original Caps Lock state. The default interval is 55 seconds.

A short press and release of the pushbutton sends the configured text, optionally followed by a carriage return. An RGB LED indicates the operating state and can change brightness to indicate activity.

Setup Mode

Holding the pushbutton for approximately three seconds switches modes. In setup mode, a VT100-compatible serial terminal provides a menu for configuring the device. No separate configuration application is required.

  • Keep-alive enable and interval (5 to 999 seconds).
  • Button text enable, text string and optional carriage return.
  • LED enable, normal brightness and activity brightness.
  • Independent colors for waiting for a terminal connection, setup and run mode.

The configuration is retained in EEPROM so that it survives power removal. Selecting the exit option returns the device to run mode.

Hardware

The original software was developed for an ATmega32U4-based board using the Arduino Leonardo board definition. A compatible 5V, 16 MHz Pro Micro is a convenient choice for a compact version.

  • D4 — pushbutton input (active high).
  • D5, D6 and D9 — red, blue and green LED outputs, respectively.
  • A1 — connection to the processor reset input for software-initiated resets.

The pushbutton requires a defined low level when released, and the LED channels require appropriate current-limiting resistors.

The Original TwoFun Units

I originally built two TwoFun units. Mine was assembled on a breadboard, while Holly's was packaged in a nice little enclosure. Both worked well, but mine eventually failed when the USB connector pulled off the microcontroller board.

Holly used only the keep-alive function and was quite happy with it. I used both functions for a while, but eventually found myself using only the text-entry feature. I let my computer go to sleep, and when I return, a press of the TwoFun button wakes it up and enters my password. That turned out to be the most useful feature for me. With the keep-alive function disabled, TwoFun became essentially a removable electronic key for my computer. I could tuck it out of sight for everyday use or simply unplug it and take it with me whenever I didn’t want to leave it accessible.

After Holly retired, she gave me hers, and I continued using it for quite some time until it suffered the same fate. I liked having that little gadget handy, so nearly three years later I ordered three new Pro Micro boards with USB-C connectors.

I may keep the next version on a breadboard again, but this time a little hot glue will provide some strain relief for the USB cable. Sometimes the simplest construction is all that is needed.

Potential USB Driver Enhancement

The original implementation saves the selected operating mode in EEPROM and resets the microcontroller when switching between keyboard operation and serial terminal configuration. This was my solution to the USB interface switching problem at the time.

A possible enhancement to the Arduino AVR USB core would provide runtime selection of USB interfaces. The ATmega32U4 supports software-controlled USB disconnection and reconnection through its USB controller.

By detaching from the host, selecting the appropriate USB descriptors, resetting endpoint and driver state, and reconnecting, the device could potentially switch interfaces without restarting the processor. The host would then enumerate the newly selected configuration.

Ideally, this would be a general-purpose extension to the Arduino USB driver rather than a modification specific to TwoFun. Another option worth investigating is retaining both interfaces as a composite USB device and selecting the active application function in software.

These are proposed enhancements, not features implemented in the original sketch.

Source Code

The sketch was developed using the Arduino Keyboard and EEPROM libraries. The original source is dated January 5, 2024.

TwoFun stores its text string in EEPROM without encryption, and the setup menu displays it. It should not be used as a secure password storage device.
